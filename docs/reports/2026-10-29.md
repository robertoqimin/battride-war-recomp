# Report of October 29, 2026: the game from start to end, chapter 4 audio, and version 0.5.2

## Summary

- **Start to end:** with an RPCS3 save with the story completed, the first mission of all 10 Chronicle chapters loads and runs, without hangs. Completing the missions, the other ~20 missions, the ending and credits, Rider Road, Free Mission and the Gallery are not validated yet: the autopilot used in the test does not complete missions.
- **Chapter 4 audio:** in the mission "近くて遠い" (stage `stg08`), about 72% of the audio blocks arrived late. Now it is 0.2% to 0.7% in combat and 0% in the second phase, the same level as the other stages.
- **Version 0.5.2:** the AppImage was built with the fix and tested end to end in a new data folder: ISO import, translation, compilation on the computer and the chapter 4 mission.

## 2. Chapter 4 audio

### Cause

- `PORT_SPU_PROFILE` showed ~3.7 billion interpreted steps of the SPU audio task in LS `0x37000`-`0x397C0`.
- That code is a 10 KB SPU module embedded in `EBOOT.ELF` (offset `0x686D00`). It is not a firmware codec.
- The task loads the module without relocation at LS `0x36F80`, and this stage runs it on every audio block. It ran entirely interpreted.

### Fix

1. **Port** (`58c073b`):
   - `scripts/build/lift_audio_spu.py` translates the module as it already did with `flashMP3.pic`: 72 functions, no unsupported instruction.
   - `spu_bridge.c` now accepts several overlays, each run only while the LS holds the instructions it was translated from.
   - On its own, this part lowered the failures to 2% to 20%. With the CPU profiler (`PORT_PROFILE`), the module's translated code became ~46% of the audio thread's time.
2. **SDK** (`ea42a29`):
   - On x86, `rotqby`, `rotqbyi`, `shlqbyi` and `cwd` in `runtime/spu/spu_helpers.h` became byte-by-byte loops, because there was only a vector path for NEON.
   - The SSE4.1 versions (`pshufb`) give results identical to the reference ones in an exhaustive test with gcc and clang.
   - The module's hottest function went from 11,037 to 8,244 instructions.
   - The change ships as a port patch, in `patches/ps3recomp/0001-spu-helpers-sse41-byte-rotates.patch`:
     - `scripts/release/build_appimage.py` applies the patch to the pinned SDK (`a6d76c8`);
     - `docs/BUILD.md` explains how to apply it to a local checkout;
     - CMake refuses to build with an SDK without the patch.

### Result

Audio failures (`PORT_AUDIO_STATS`, late blocks against the total):

| Build | Chapter 4, 1st phase combat | Chapter 4, 2nd phase | Final mission |
|---|---|---|---|
| Before | ~72% | n/m | <0.4% |
| Module translated only | 2-20% | n/m | n/m |
| Local, module + SDK patch | 0.2% (32/15,008) | 0% (3 min) | 0.03% (8/26,264) |
| AppImage 0.5.2, compiled on the computer | 0.7% (160/23,450) | 0% (2.5 min, 60 fps) | n/m |

n/m = not measured.

In the AppImage, the first phase's losses come in peaks of up to 3.8% in a 5-second window, most of them right after entering the mission. The autopilot did not reach the chapter 4 boss fight.

## 3. AppImage 0.5.2

- **Version:** `scripts/release/build_appimage.py`, the README and `docs/APPIMAGE.md`, with a note "Chapter 4 audio in 0.5.2".
- **Build:**
  - made in the `battride-build:ubuntu22.04` container, with the PGO profiles from `build-pgo11/pgo`;
  - the type2 runtime and 7-Zip came from the 0.5.1 build and match the SHA-256 recorded in its `package.json`;
  - result: `dist/v0.5.2/BattrideWarRecomp-v0.5.2-x86_64.AppImage`, 236 MB, SHA-256 `8dd96ccd3698ec7934d8546184c3440544f787901d8bc80c78120a9ca48a10f3`.
- **Contents:** the packaged SDK contains the patch, and `patches/ps3recomp/` is in the public sources.
- **`--check`:** passed.
- **Import with `--import-only`** into a new folder (`~/battride-test-0.5.2`), limited to 3 cores and 8 GB:
  - RPCS3 download, import and translation: ok;
  - the build reported `module: 72 entries translated` and `audio SPU module: translated`;
  - compilation in 19 minutes with 3 jobs and PGO profiles;
  - `build.json` records package 0.5.2.
- **Game:** the runner the AppImage compiled loaded the complete save, entered the chapter 4 mission and logged "translated task and overlays". Results in the table of section 2.
